Keyboard shortcuts

Vantage is keyboard-first, while keeping essential actions available through visible controls and menus.

ActionShortcut
New tabCtrl + T
Close tabCtrl + W
Restore closed tabCtrl + Shift + T
Focus address barCtrl + L
ReloadCtrl + R
Find in pageCtrl + F
FullscreenF11
Developer toolsF12 or Ctrl + Shift + I
Select tab 1–9Ctrl + 1 … 9
Navigate suggestions↑ / ↓, then Enter

Tabs and the mouse

Drag a tab along its tab strip to reorder it. Drop it on another open Vantage window to move it there, or drop it away from a Vantage tab strip to open it in a new window.

Hover the tab strip and scroll down to move to the next tab or up to move to the previous tab. Scrolling stops at the first and last tabs.

Fullscreen from the command line

Launch a normal browser window in fullscreen with vant --fullscreen, optionally followed by a URL:

vant --fullscreen https://nift.dev

Use F11 to leave or re-enter fullscreen.

Application mode

Use --app to open a site in a dedicated window without tabs, the address bar, downloads button or settings menu:

vant --app https://nift.dev
vant --app=https://nift.dev

Add --fullscreen to start the application window in fullscreen:

vant --app https://nift.dev --fullscreen

Vantage Browser is built in the open for Linux.
