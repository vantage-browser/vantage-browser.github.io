Build Vantage directly against the system GTK4, WebKitGTK 6.0 and SQLite libraries. The project is intentionally a native C++20 build rather than an Electron/Chromium bundle.

Dependencies

# Ubuntu / Debian
sudo apt install build-essential pkg-config python3 \
  libgtk-4-dev libwebkitgtk-6.0-dev libsqlite3-dev

# Verify discovery
pkg-config --modversion gtk4 webkitgtk-6.0 sqlite3

Build

make
./build/vant --version
./build/vant https://example.com

The Makefile uses C++20, warnings-as-errors and system pkg-config metadata. JS++ is pinned under third_party/jspp and linked into the native build.

Tests

make test-unit
make smoke
make test
make test-sanitize
make vendor-integrity
make vendor-check

test-unit includes model/state tests, desktop-entry validation, agent security tests and JS++ adapter/automation coverage. Native agent/browser tests require a graphical WebKit-capable environment.

Agent-native regression

make test-agent-native

This launches a real Vantage instance, exercises the local agent surface, then tears it down. Run it in an environment where GTK/WebKit can create a browser window.

Useful probes

./build/vant --headless-smoke
./build/vant --native-probe
env WEBKIT_DISABLE_COMPOSITING_MODE=1 ./build/vant --native-smoke
