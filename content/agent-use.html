Vantage exposes a stable local control plane for trusted software agents. An agent controls the same live WebKitGTK browser the human is using: real windows, tabs, profile state and visible interaction. These docs intentionally optimize for agent retrieval and precise implementation rather than brevity.

Five commands to remember

vant agent status
vant agent capabilities
vant agent tabs
vant agent snapshot 1
vant agent fetch https://api.example.com/status

Everything else is reachable through vant agent call METHOD JSON. Arbitrary page logic is available through vant agent js.

Discover before assuming

vant agent version
vant agent capabilities
vant agent call describe '{}'
vant agent call describe '{"name":"page.interact"}'
vant agent call describe '{"name":"net.fetch"}'

Protocol 1 is stable but additive capabilities are expected. Query the installed browser rather than assuming a remembered method exists.

Normal page-control loop

vant agent tabs
vant agent open https://example.com 1
vant agent call page.wait '{"tab_id":1,"text":"Example Domain","timeout_ms":5000}'
vant agent snapshot 1
vant agent click @e3_2 1
vant agent snapshot 1

Refs such as @e3_2 are disposable generation-scoped handles. After DOM mutation or navigation, resnapshot. On stale_or_missing, never guess a replacement ref.

API-control loop

vant agent fetch https://api.example.com/v1/items
vant agent fetch https://api.example.com/v1/items '{"method":"POST","headers":{"Content-Type":"application/json"},"body":"{\"name\":\"agent-created\"}"}'

Use net.fetch for HTTP/API work. Use the page when the task depends on rendering, DOM state or the user's browser session.

Preferred abstraction order

API request              -> net.fetch
Browser/tab lifecycle    -> browser.*
Routine DOM operation    -> page.snapshot + page.interact
Wait for state           -> page.wait
Read content             -> page.inspect
Debug page behavior      -> page.diagnostics
Exceptional DOM logic    -> page.javascript
WebKit properties        -> webkit.*

Human and agent share one browser

Agent actions affect the visible Vantage UI. Preserve unrelated human tabs, use explicit IDs, and expect the human or another controller to change state between observations.

Errors are information

not_found: refresh tabs/windows. stale_or_missing: resnapshot. timeout: inspect diagnostics before deciding to wait or reload. fetch_error: transport failed. HTTP 404/500 from net.fetch is a normal result with ok:false.

Trust model

The local agent is trusted; loaded websites are not. RPC is same-user local IPC. Pages receive no privileged Vantage bridge. page.javascript remains page-context JavaScript. net.fetch does not silently inherit browser credentials.
