Vantage minimizes browser-vendor data collection by having no required Vantage account, telemetry service or cloud sync. That does not make ordinary web traffic anonymous: websites and network services still receive what browsing requires.

No Vantage telemetry account

Vantage does not require sign-in to a Vantage service and does not phone home for analytics. Browser-owned history, bookmarks, sessions and settings are local.

What still leaves the machine

Normal web requests, DNS, search queries, downloads and any explicit agent/API request necessarily contact remote systems. A website can observe requests according to normal web behavior; Vantage's local-data posture does not override that.

Agents and privacy

A trusted local agent can read and operate browser state exposed by protocol 1. Treat granting agent access like granting another same-user desktop tool access. net.fetch does not silently inherit page cookies, which keeps API credentials explicit.

Downloads and local records

Downloaded files, bookmarks and history can themselves contain sensitive information. They are local data, not harmless data; protect the user account/profile accordingly.

Clearing site state

Site information provides controls for clearing site cookies. Clearing browser state cannot retract data already sent to a remote service.
