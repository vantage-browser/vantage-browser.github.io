Exact local control protocol for agents. The Unix socket is owned by the running Vantage process and uses same-user filesystem permissions.

Envelope

{"version":1,"id":"request-id","method":"browser.tabs","params":{}}

Replies carry the same protocol version and request ID, with either ok:true,result or ok:false,error. Unknown methods and invalid parameters are explicit failures.

CLI escape hatch

vant agent call METHOD '{"parameter":"value"}'
vant agent js 'document.title'
vant agent js --file script.js
cat script.js | vant agent js -

Current namespaces

browser.* controls live windows, tabs and navigation. page.* covers JavaScript, semantic snapshots/interactions, waits, screenshots/content and diagnostics. WebKit/Vantage service methods expose settings, browser data and capabilities. Query capabilities and describe rather than assuming a method exists on every installed version.

A12 concurrency contract

Independent local clients are serviced concurrently while WebKit mutations are marshalled onto GTK's main context. A slow client does not serialize unrelated clients. Closed tab/window IDs and invalidated semantic references fail explicitly and are never rebound to new objects.

A13 CLI shortcuts and output

vant agent tabs
vant agent open https://example.com 1
vant agent snapshot 1
vant agent click @e3_4 1
vant agent fill @e3_7 hello 1
vant agent diagnostics 1
vant agent --json capabilities

Exit status is 0 for success, 1 for runtime/RPC failure and 2 for invalid CLI usage. Default output is the concise result; --json emits the complete protocol envelope. call remains the universal method escape hatch, and JavaScript accepts inline text, a file or stdin.

A14 direct clients

The Unix RPC is the authoritative interface, not the CLI. The source tree includes a dependency-free Python reference client showing framing for integrations. Vantage has no Gantry dependency: Cortex, Warden, Codex, Claude Code, OpenCode, scripts and custom agents can all use the same contract. An MCP adapter can be layered over RPC later without creating a second control implementation.

python3 tools/vant_agent.py browser.tabs '{}'
python3 tools/vant_agent.py page.snapshot '{"tab_id":1}'
