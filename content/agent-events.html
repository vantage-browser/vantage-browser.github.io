Diagnostics and asynchronous browser behavior for agents. This page is intentionally detailed and evolves checkpoint-by-checkpoint with the implementation.

A10 diagnostics

vant agent call page.diagnostics '{"tab_id":1}'
vant agent call page.diagnostics.clear '{"tab_id":1}'
vant agent call page.native_diagnostics '{"tab_id":1}'

The page diagnostics ring records bounded console calls, JavaScript errors and unhandled rejections. Native diagnostics report top-level load failure and WebKit web-process termination. Vantage does not claim arbitrary CDP-style response-body capture where WebKitGTK does not expose a clean equivalent.

Page privilege rule

The diagnostics recorder observes page-visible state but exposes no privileged Vantage object. A hostile page cannot call the agent RPC simply because an agent can inspect that page.

A11 event sequence

vant agent call events.since '{"after":0,"limit":256}'
vant agent events

Events use monotonically increasing sequence numbers. Clients reconnect by asking for events after their last consumed sequence. The application ring is bounded and reports dropped events after overflow. vant agent watch follows the cursor continuously with client-side polling. Direct integrations can choose their own polling cadence; slow clients never hold WebKit's main thread waiting for consumption.
