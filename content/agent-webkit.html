Vantage provides high-level semantic operations for efficiency and deep WebKit/page access when those abstractions are insufficient.

Arbitrary JavaScript

vant agent js 'document.title'
vant agent call page.javascript '{"tab_id":1,"script":"location.href"}'

Evaluation is requested by the trusted application. It does not grant the loaded page a reverse bridge into Vantage.

Semantic snapshots

vant agent call page.snapshot '{"tab_id":1}'
# returns compact refs such as @e3_17
vant agent call page.interact '{"tab_id":1,"ref":"@e3_17","action":"click"}'

References are deliberately stale after relevant DOM mutation/navigation rather than silently pointing at another element.

Inspection

Agents can inspect rendered/content state, screenshots, viewport/scroll/zoom/find state, browser settings and capability-described WebKit properties. Use semantic operations for routine work and arbitrary JavaScript/WebKit introspection as the escape hatch.
