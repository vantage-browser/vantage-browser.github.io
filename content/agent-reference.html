Trust boundary

The local agent is deliberately trusted with user authority. Web content is not. RPC is application-side; page JavaScript never receives a Vantage host object, socket capability, filesystem bridge or process-execution primitive.

A15 security invariants

The local RPC socket is same-user only and requests are bounded. Page content cannot invoke Vantage RPC merely by being loaded and receives no privileged native/JS++ host bridge. Agent-requested JavaScript executes in page context without converting the page into native application code.

A16 performance bounds

Agent state is bounded rather than allowed to grow with a long browsing session: semantic snapshots cap interactive elements, diagnostics and event history use bounded rings, and event reads are capped. The local RPC acceptor sleeps while idle. Native WebKitGTK latency and sustained Wayland browsing remain release-host measurements rather than claims inferred from the UI-independent benchmark.
