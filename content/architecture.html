Vantage is a browser shell with a deliberately explicit division of responsibility.

GTK applicationWindows, controls and Linux integration
→
Vantage modelTabs, sessions, history and policy
→
WebKitGTKWeb content, media and rendering

Not a Chromium fork

Vantage contains no Chromium or Blink code. Familiar controls are a usability choice, not shared browser architecture.

JS++

A pinned copy of JS++ provides a bounded foundation for future privileged commands and automation. Normal page JavaScript continues to run in WebKit. The current browsing experience does not depend on exposing JS++ to websites.

Persistent state

SQLite stores browser records such as history, bookmarks, sessions and downloads. Rendering preferences use a small local configuration file so they can be applied before WebKit starts.
