Vantage documentation

Desktop integration

The installer registers Vantage as a Linux desktop application with a stable application ID and icon.

Launcher identity

The desktop file and GTK application use cv.vantage_browser.Vantage. This lets Wayland compositors associate new windows with the Vantage launcher instead of a generic executable icon.

Refresh launchers

update-desktop-database ~/.local/share/applications
gtk-update-icon-cache -f ~/.local/share/icons/hicolor

Most desktops notice the new launcher automatically. Log out and back in only if the compositor retains an old application identity.

Open links

The packaged desktop entry accepts HTTP and HTTPS URLs. Default-browser selection remains a desktop setting and should be changed only after you are comfortable with the preview.

Vantage Browser is built in the open for Linux.
