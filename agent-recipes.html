Agent recipes

Executable patterns intended for agents driving the same visible Vantage session as the human user.

Inspect and operate a page

vant agent call browser.tabs '{}'
vant agent call page.snapshot '{"tab_id":1}'
vant agent call page.interact '{"tab_id":1,"ref":"@e1_4","action":"click"}'
vant agent call page.wait '{"tab_id":1,"text":"Welcome","timeout_ms":5000}'

Debug a frontend

# after rebuilding/reloading the application
vant agent call page.diagnostics.clear '{"tab_id":1}'
vant agent call browser.reload '{"tab_id":1}'
vant agent call page.diagnostics '{"tab_id":1}'
vant agent call page.snapshot '{"tab_id":1}'

Use arbitrary JavaScript when semantic operations are not expressive enough. The agent is operating the user's actual tab, so human observation/intervention remains possible.

A13 compact CLI workflow

vant agent tabs
vant agent snapshot 1
vant agent click @e2_5 1
vant agent diagnostics 1

Prefer these compact forms for routine operation and fall back to vant agent call or arbitrary JavaScript for the complete surface.

Vantage Browser is built in the open for Linux.
