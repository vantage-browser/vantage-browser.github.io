01 / PRINCIPLES

The browser should be the frame.
Not the picture.

Vantage is being designed around the work of browsing: fast navigation, durable sessions, clear permissions and direct keyboard control. No account requirement. No default telemetry. No attention-hungry chrome.

01

Small by intent

Measure startup, memory and background activity before making claims. Keep features only when they earn their footprint.

02

Native to Linux

Wayland first, with Omarchy as the reference desktop—not a web app wearing a desktop window.

03

Keyboard fluent

Tabs, workspaces, commands and navigation remain close at hand without making the interface cryptic.

04

Local by default

Your history, profiles and sessions belong on your machine. Private browsing has a real non-persistence contract.

02 / ARCHITECTURE

A practical first engine

The web, without rebuilding the entire web.

WebKitGTK handles standards-compatible page rendering and untrusted site JavaScript. Vantage owns the browser experience around it.

  1. InterfaceGTK + WaylandWindows, input, portals and desktop integration
  2. BrowserVantage CoreTabs, workspaces, profiles, policy and recovery
  3. WebWebKitGTKHTML, CSS, page JavaScript, media and accessibility
  4. ScriptJS++Bounded privileged commands and automation
03 / TRAJECTORY

First make it honest.
Then make it fast.

The project advances through evidence-backed checkpoints. Performance, compatibility and security claims arrive only when their tests do.

V0—V2

Open the view

Reproducible GTK shell, safe navigation, tabs and complete keyboard control.

V3—V5

Make it daily

Profiles, crash recovery, downloads, permissions and a measured lifecycle baseline.

V6—V8

Make it programmable

Pinned JS++ embedding, capability-limited automation and a full isolation review.

V9—V11

Make it real

Omarchy packaging, sustained dogfooding, compatibility evidence and a public preview.
