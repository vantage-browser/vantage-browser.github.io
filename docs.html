What Vantage is

Vantage is not a Chromium fork and contains no Chromium or Blink code. It is a native GTK browser whose pages are rendered by WebKitGTK. Vantage implements its own browser chrome, tabs, address bar, history, bookmarks, downloads and local browser model.

Current target

The first target is Linux on Wayland, with Omarchy and Arch-based systems as the primary public-preview environment. Broader packaging should follow retained compatibility testing rather than assumption.

Vantage Browser is built in the open for Linux.
