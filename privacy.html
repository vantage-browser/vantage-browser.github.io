Vantage documentation

Privacy

Vantage is designed without telemetry, an account system or a cloud synchronization dependency.

Stored locally

Bookmarks, history, downloads, favicons, permissions, tabs and preferences live in Vantage’s local profile directories. Search and address suggestions are derived from local history.

Private windows

Private windows use an ephemeral WebKit network session and do not write Vantage browsing history or downloads to the normal profile database. Private browsing does not make a user anonymous to websites, networks or internet providers.

Search

Text that is not recognized as a URL is sent to Brave Search. The search provider receives the query and ordinary network metadata according to its own service.

No inflated claims

Vantage does not claim that using WebKitGTK alone makes browsing private or secure. Its privacy position comes from a smaller local product model: no Vantage telemetry, no required account and no Vantage-operated cloud service.

Vantage Browser is built in the open for Linux.
