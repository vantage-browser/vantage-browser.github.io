Trust boundary

The local agent is deliberately trusted with user authority. Web content is not. RPC is application-side; page JavaScript never receives a Vantage host object, socket capability, filesystem bridge or process-execution primitive.

A15 security invariants

The local RPC socket is same-user only and requests are bounded. Page content cannot invoke Vantage RPC merely by being loaded and receives no privileged native/JS++ host bridge. Agent-requested JavaScript executes in page context without converting the page into native application code.

A16 performance bounds

Agent state is bounded rather than allowed to grow with a long browsing session: semantic snapshots cap interactive elements, diagnostics and event history use bounded rings, and event reads are capped. The local RPC acceptor sleeps while idle. Native measurements on the supported GTK4/WebKitGTK development host: sub-millisecond RPC round trips, snapshots in 1-5 ms, and 0.03% idle CPU when the agent service is unused.

A17 compatibility status

Wire protocol 1 is stable v1, frozen after the native certification wall (clean native build and tests, real graphical shared human+agent dogfooding, hostile-page boundary testing, concurrency and performance). Agents should still query capabilities and describe and tolerate additive fields.

Vantage Browser is built in the open for Linux.
