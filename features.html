Purposeful essentials

A browser, not a platform.

Vantage combines a native Linux interface with WebKitGTK and keeps the browser model, interface and local data under its own control.

Browse every day

Multiple tabs, address history suggestions, Brave Search, back and forward navigation, reload and stop, downloads, bookmarks and session restoration.

Stay oriented

Most-visited sites on the New Tab page, favicons, source viewing, find in page, zoom and keyboard tab switching.

Know the site

Site information exposes connection state, certificate details and controls for clearing site cookies.

Build for the web

Docked WebKit developer tools provide Elements, Console, Sources, Network, storage and debugging tools.

Keep data local

History, bookmarks, sessions and settings are stored locally. Private windows use ephemeral storage and do not write history.

Use Linux naturally

GTK controls, Wayland behavior, a desktop launcher and a native application identity fit modern Linux desktops.

Vantage Browser is built in the open for Linux.
