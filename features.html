Vantage documentation

Features

Vantage is a native Linux WebKitGTK browser designed to stay small, local and useful to both humans and trusted software agents. Ordinary browsing does not depend on an AI service or Vantage cloud account.

Browsing and navigation

Multiple tabs/windows, back/forward, reload/stop, address/search input, history suggestions, favicons, New Tab search, middle-click close, drag reorder, cross-window tab transfer and detach-to-window. Window geometry is remembered.

Downloads, bookmarks and history

Downloads expose progress, cancellation, link copying, deletion and “show in Files”. Dedicated Downloads, Bookmarks and History views support search and bulk operations. Browser records live locally in SQLite.

Page and developer tools

Find-in-page, zoom, print, highlighted view source, image viewing/saving/copying and WebKit developer tools cover normal inspection. Site information reports connection/certificate state when WebKit exposes it and can clear site cookies.

Sessions and privacy modes

Ordinary profiles restore sessions and persist cookies. Private windows use ephemeral browsing state and do not write normal history. Vantage itself requires no account or telemetry service.

Linux-native integration

GTK4, WebKitGTK 6.0, Wayland behavior, stable application identity, XDG desktop launcher and hicolor icon make Vantage a normal Linux desktop application. See Desktop integration.

Rendering and media

Compatibility and accelerated video-rendering modes account for variation across Linux graphics stacks and VMs. Compatibility is conservative by default; accelerated rendering is opt-in. See Video rendering.

Agent-native control plane

Trusted same-user agents operate the same live browser through stable protocol 1: discovery, tabs/windows, navigation, bounded semantic snapshots, ref-based interaction, waits, inspection, JavaScript, screenshots, diagnostics/events and WebKit state.

Direct APIs without rendering

net.fetch lets agents call HTTP APIs with explicit method, headers, body, timeout and response limits. It is application-side and deliberately does not inherit page cookies.

vant agent fetch https://api.example.com/status
vant agent fetch https://api.example.com/items '{"method":"POST","headers":{"Content-Type":"application/json"},"body":"{\"name\":\"demo\"}"}'

What Vantage deliberately is not

It is not a Chromium fork, not a cloud browser, and not a browser welded to one model provider. Web content remains WebKit content; agent authority remains an explicit local application capability.

Vantage Browser is built in the open for Linux.
