Vantage documentation

Installation

The public installer supports Arch, Omarchy, Debian, Ubuntu, Fedora and openSUSE systems that provide WebKitGTK 6.0. It downloads a checksummed tagged source release, builds Vantage against the target system libraries, then installs the binary, desktop launcher and icon.

Install

curl -fsSL https://vant.cx/install.sh | sh

Do not run the command with sudo. The installer invokes sudo only for distribution packages and installs Vantage itself for the current user.

Distribution support

Arch and Omarchy use pacman, Debian and Ubuntu use apt, Fedora uses dnf, and openSUSE uses zypper. The installer requires WebKitGTK 6.0 and installs the compiler, development libraries and media packages needed for a local build. Additional codec packages remain optional on Fedora and openSUSE when their configured repositories do not provide them.

Release selection

Normal installation follows the latest GitHub release rather than the development branch. To install or roll back to an exact tagged version:

curl -fsSL https://vant.cx/install.sh | VANT_VERSION=v0.1.0 sh

What is installed

  • ~/.local/bin/vant
  • ~/.local/share/applications/cv.vantage_browser.Vantage.desktop
  • ~/.local/share/icons/hicolor/512x512/apps/cv.vantage_browser.Vantage.png
  • Build, GTK, WebKitGTK, SQLite and GStreamer packages when missing

Right-click the installed launcher in a compatible application menu or dock to open a new normal or private window.

Command-line launch modes

Open a URL normally, start fullscreen, or run a site as a standalone application without normal browser chrome:

vant https://nift.dev
vant --fullscreen https://nift.dev
vant --app https://nift.dev
vant --app=https://nift.dev --fullscreen

Press F11 to enter or leave fullscreen at any time.

Update

curl -fsSL https://vant.cx/update.sh | sh

Uninstall

curl -fsSL https://vant.cx/uninstall.sh | sh

Normal uninstall preserves your browser profile. To also remove local history, bookmarks, settings and session data:

curl -fsSL https://vant.cx/uninstall.sh | sh -s -- --purge
Preview software

Vantage is early software. Keep another browser available, review known limitations and report reproducible failures with your WebKitGTK version.

Vantage Browser is built in the open for Linux.
